## Findings addressed

The original wrapper could lose an analysis variable when absorption failed
before its restoration loop. This was reproduced with an invalid FE variable
and a changed data signature. The new preserve/restore boundary encloses all
working-data mutations, including upstream failures.

The original manual absorb-name parsing was replaced with reghdfe's own sample
selection. This also handles string FE, interactions and heterogeneous slopes.
Working residuals retain double precision even for integer/float inputs.
Named FE generated by reghdfe are removed between projections, so repeated
partialling does not collide with previously generated FE names.

The upstream breakdown plot creates x and y. Graph calls are isolated so common
analysis names and graph failures cannot alter the caller's dataset. Use the
wrapper's plot subcommand for this protection.

The original help incorrectly equated overall and residualized R-squared.
Documentation now distinguishes those scales and identifies fixed effects as
noncomparison controls throughout.

## Remaining boundaries

- No publication to GitHub or network installation from the intended GitHub URL
  was performed.
- This is a small-panel correctness suite, not a large-panel performance
  benchmark or proof of the underlying identification assumptions.
- Graph execution was tested; no visual design review was performed.
- The upstream finite-rybar restrictions and some default noproduct grid failures
  remain. The tested explicit-grid example is documented.
- Analysis names are limited to 31 characters and cannot conflict with upstream
  residual names; weights, factor/time-series analysis variables and VCE options
  are not supported.
- The bootstrap is an illustration, not an inference recommendation.
